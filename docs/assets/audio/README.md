# Звуковые дорожки

Книга включает средовой звук только после действия читателя и только если
дорожки действительно есть в репозитории. Пока файлов нет, кнопка «Звук»
честно заблокирована и подписана «Звук готовится».

Положите сюда пять файлов — по одному на природную зону:

| Файл            | Зона              | Что слышно                                    |
|-----------------|-------------------|-----------------------------------------------|
| `mountains.mp3` | горы и сопки      | ветер, дальние птицы, редкие осыпи            |
| `forest.mp3`    | лес               | листва, насекомые, дождь, треск               |
| `river.mp3`     | реки и долины     | течение, вода по камням, птицы у воды         |
| `coast.mp3`     | побережье         | прибой, галька, ветер                          |
| `sea.mp3`       | море              | приглушённая подводная акустика               |

Требования:

- реальные записи природных сред, **без музыки**;
- 1–3 минуты, зацикленные без слышимого стыка (кроссфейд на краях);
- MP3, 96–128 кбит/с, моно или стерео — вес каждого файла до ~1,5 МБ;
- уровень громкости выровнен между дорожками: переход между зонами не должен
  пугать скачком;
- права на запись должны позволять публикацию.

Порядок зон соответствует пяти уровням сцены: горы → лес → реки → побережье →
море. Смена дорожки происходит по прокрутке сцены и плавно: текущая уходит,
соседняя подмешивается.
