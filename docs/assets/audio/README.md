# Звуковые дорожки

Книга включает атмосферу только после действия читателя и только если
дорожки действительно есть в репозитории. Пока файлов нет, кнопка «Звук»
честно заблокирована и подписана «Звук готовится».

## Ландшафты разделов (корень папки)

У каждого крупного раздела книги своя среда — манифест
`docs/content/soundscape.json`, громкость и переходы — `docs/assets/js/audio.js`.
При переходе между главами дорожка меняется плавным переходом (~2,4 с):
два ландшафта не звучат одновременно на полной громкости.

| Файл          | Раздел | Что слышно                                       |
|---------------|--------|--------------------------------------------------|
| `island.mp3`  | Остров | ветер, птицы, горы и лес                         |
| `sea.mp3`     | Море   | волны, прибой, чайки, подводный шум              |
| `forest.mp3`  | Лес    | листва, насекомые, дождь, птицы                  |
| `game.mp3`    | Дичь   | лес, звери и птицы                               |

Заполняется по мере готовности: можно положить файлы по одному — доступные
разделы звучат, остальные честно отмечаются «дорожка готовится».

Требования:

- **реальные полевые записи**, предпочтительно — с Сахалина; без музыки
  и без буквального «озвучивания» текста: звук создаёт присутствие,
  а не иллюстрирует то, что написано;
- 1–3 минуты, зацикленные без слышимого стыка (кроссфейд на краях);
- MP3, 96–128 кбит/с, моно или стерео — вес каждого файла до ~1,5 МБ;
- уровень громкости выровнен между дорожками: смена раздела не должна
  пугать скачком;
- права на запись должны позволять публикацию (лицензия или собственная
  запись); источник и лицензию — в `README.md` проекта.

## Голос автора (`narration/`)

Озвучка глав — отдельный слой со своим манифестом `docs/content/narration.json`
и плеером `docs/assets/js/voice.js`: фрагменты звучат подряд, позиция и
скорость запоминаются, голос и атмосфера регулируются независимо.
Манифест растёт по мере озвучки глав; тест `test/narration.test.js` следит,
чтобы фрагменты и главы не расходились.
